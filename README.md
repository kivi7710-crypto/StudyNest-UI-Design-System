# StudyNest-UI-Design-System
🌷 StudyNest – UI Design System

UI/UX Design Project

📌 Project Overview

This project focuses on creating a reusable UI design system for StudyNest, a student productivity application concept.

The design system includes reusable components, colour styles, typography, spacing and visual effects to maintain consistency across the application.

🎨 Design System Components

1. Colour Styles

Primary, secondary, background, text, success and error colours.

2. Typography

Heading styles, body text, captions and button text.

3. Buttons

Primary, secondary, outline and disabled button variants.

4. Input Fields

Default, focused, error and disabled input states.

5. Cards

Task cards, notes cards and progress cards.

6. Navigation

Bottom navigation with active and inactive states.

7. Modals

Confirmation, success and warning dialogs.

8. Effects and Spacing

Consistent shadows, corner radius and spacing values.
